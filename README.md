# বাজার দর (BazarDor)

BazarDor is a simple and user-friendly grocery price tracking website built to help people check the prices of everyday essentials in one place. Users can explore different product categories, view product details, and stay informed about current market prices.

## Technologies Used

- **Next.js** – React framework for building the application
- **React** – For creating reusable UI components
- **Tailwind CSS** – For styling and responsive design
- **JavaScript** – Main programming language
- **Better Auth** – For user authentication and session management
- **MongoDB** – For storing user and authentication data

## Key Features

1. **Browse Products:** Explore everyday grocery products and their prices from the homepage.
2. **Product Categories:** Find products easily by browsing different categories.
3. **Product Details:** View individual product information, including current prices and other available details.
4. **User Authentication:** Create an account, sign in, and securely access your profile.
5. **Profile Management:** View account information and update your name through the profile update page.
